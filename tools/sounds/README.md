# Bundled study loops — generator

The five ambient loops in `app/src/main/res/raw` used to be generated by a
script that lived in a shell history and then stopped existing. This is that
script, written down, extended to seven sounds, and given tests.

```bash
python -m tools.sounds.generate                 # overwrite the app's assets
python -m tools.sounds.generate --out /tmp/a    # audition without touching the app
python -m tools.sounds.generate --only night_rain --seconds 15
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 pytest tools/sounds -q
```

Needs `numpy` and `soundfile` (libsndfile ≥ 1.2 for Vorbis writing). Nothing in
the Android build runs this; the `.ogg` files are checked in.

## What changed, and why it was worth changing

The old assets were **22.05 kHz mono WAV**. Both halves of that hurt:

* 22.05 kHz puts a hard wall at 11 kHz. Rain, fire and surf are *identified* by
  what happens above that wall, so every one of them arrived as a version of
  the same dull hiss.
* Mono is the wrong shape for ambience. A sound meant to sit around you for
  twenty-five minutes and not be listened to is exactly the sound that most
  needs width; a mono loop sits in the middle of your head and stays there.

They are now **44.1 kHz stereo OGG Vorbis**, and the whole set of seven is
7.7 MB against the old five's 12 MB. The bitrate is not guessed — see the
swirl test below.

## Seamless without a crossfade

The old loops were made seamless by crossfading the last three seconds into the
first three. That works, but those three seconds are two takes summed at
reduced level, so the density visibly dips once a minute — and with rain or
fire, a dip in event density is precisely what the ear is listening to.

Everything here is **circular by construction** instead, which means a loop
that is periodic to the sample with no fade anywhere:

| Layer | Made circular by |
| --- | --- |
| Noise beds | Built in the frequency domain — an inverse real FFT of `n` bins is periodic in `n`. A time-domain filter is not, which is why there isn't one anywhere in this code. |
| Modulation | `lfo()` takes an integer number of cycles *per loop*, so the envelope meets itself. |
| Events (drops, crackles) | `add_wrapped()` — an event near the end continues over the beginning. |
| The pad's partials | Frequencies snapped to exact multiples of 1/loop. At 75 s that grid is 1/75 Hz, far finer than the ear resolves, so detuning survives the snap. |

`test_the_seam_is_not_a_click` holds this: the step from the last sample back
to the first must be no larger than an ordinary 99th-percentile step.

## Levelling

Every loop is levelled to the same K-weighted loudness (`TARGET_LUFS`). This is
why `FocusSound` no longer carries a per-sound `gain`: those five hand-tuned
numbers were levelling by peak and missing by up to 5 dB, so switching from
Deep noise to Night rain was a real jump in level.

Beds are set by RMS and gated layers (surf foam, wind in the needles) by peak.
A layer that is silent for most of the loop has a tiny RMS, so setting it that
way scales its crests to enormous peaks and forces the final levelling stage to
pull the entire sound down — which is exactly what made Ocean waves 6 dB quiet
before `at_peak` existed.

## The encoder setting is measured, not chosen

Noise is the hardest material there is for a transform codec. Pushed too far,
Vorbis's quantisation floor pumps band by band and the rain starts washing in
and out — "swirl". It is audible long before any spectral average moves, so
`test_encoder_setting_does_not_make_noise_swirl` measures the *variance over
time* of per-octave-band energy and asserts the decoded file fluctuates no more
than the source. At `COMPRESSION_LEVEL = 0.6` (~120 kbps) the excess is under
0.1 dB. Re-run that test before lowering the bitrate further.

## Adding a sound

1. Write the generator in `loops.py`, returning `(frames, 2)` in -1..1.
2. Add it to `LOOPS` with a fixed seed — the assets must be reproducible.
3. Add the matching entry to `FocusSound` in the app. **The id is the file
   name and the stored setting value**; if they disagree the app silently falls
   back to the default sound rather than failing.
4. Regenerate, and run the tests.
